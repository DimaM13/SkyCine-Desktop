# 🎬 SkyCine Cinema Desktop

> Автономный десктопный клиент с нативным аппаратным движком **MPV Engine (Direct3D11 / Vulkan)** для воспроизведения любых видеоформатов без перекодирования (Bit-Perfect Direct Play).

---

## ✨ Возможности

- 🚀 **Native MPV Video Engine:** прямое воспроизведение HEVC, 4K HDR, AV1, 10-bit, DTS, AC3, TrueHD без нагрузки на процессор.
- 🍿 **Фирменный интерфейс SkyCine:** золотой прогресс-бар, быстрый выбор дорожек и субтитров, адаптивные панели управления.
- 👥 **Watch Together (Совместный просмотр):** моментальная синхронизация воспроизведения с комнатами, живой чат и реакции.
- 🖥️ **Windows Native Integration:** управление с аппаратным аппаратным дескриптором окна (`--wid`), автоматический ресайз и интеграция.
- 📦 **Готовые установщики:** быстрая сборка в `.exe` (NSIS Installer и Portable).

---

## 🛠️ Установка и запуск в разработке

1. **Установка зависимостей:**
   ```bash
   npm install
   ```

2. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```

3. **Сборка и запуск релизной версии:**
   ```bash
   npm start
   ```

---

## 📦 Сборка Windows `.exe` дистрибутивов

- **Сборка инсталлятора (Setup .exe):**
  ```bash
  npm run package:exe
  ```

- **Сборка Portable версии (без установки):**
  ```bash
  npm run package:portable
  ```

Готовые исполняемые файлы будут сохранены в папке `release/`.
